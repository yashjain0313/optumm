WHAT IT DOES
------------
A personal healthcare benefits portal where employees log in
with their SAP ID + password and see their own:

  - HSA / FSA balances (Health Savings & Flexible Spending Accounts)
  - Deductible progress (how much they've paid vs. their annual limit)
  - Copay rates (primary care, specialist, urgent care, prescriptions)
  - Transaction history (past medical payments)
  - IRS 2026 rulebook (legal contribution limits, plan rules)
  - Pay copay directly from HSA or FSA wallet

Each employee sees ONLY their own data. Fully authenticated.


HOW IT WORKS (TECH STACK)
--------------------------
BACKEND  →  FastAPI (Python) + PostgreSQL (Neon cloud DB)
FRONTEND →  React (Vite) → communicates via /api proxy

  Login Flow:
  1. Employee enters SAP ID + password on login page
  2. Backend verifies against DB (bcrypt hashed password)
  3. Returns a JWT token
  4. Frontend stores token, uses it for every API call

  API Endpoints:
  POST /api/auth/login       → get JWT token
  GET  /api/member           → name, plan, employer, age
  GET  /api/wallet           → HSA/FSA balances + IRS limits
  GET  /api/benefits         → deductible, OOP max, copay rates
  GET  /api/transactions     → payment history
  GET  /api/rules            → full IRS 2026 rulebook
  POST /api/wallet/pay-copay → deduct from HSA or FSA

  Database (NeonDB - PostgreSQL):
  employees   → SAP ID, hashed password, name, plan, age
  wallets     → HSA/FSA balances, contributions YTD
  benefits    → deductible, out-of-pocket max, copay rates
  transactions → payment history per employee


HEALTHCARE INDUSTRY RELEVANCE
------------------------------
Problem it solves:
  Employees don't understand their benefits. They don't know:
  - How much is left in their HSA/FSA
  - Whether they've hit their deductible
  - How much a copay will actually cost them
  - What the IRS rules say about their plan

This portal solves exactly that.

Key talking points for presentation:

1. COST TRANSPARENCY
   Members can see real-time balances and copay rates before
   visiting a doctor. Reduces surprise billing shock.

2. HSA/FSA COMPLIANCE
   App enforces IRS 2026 limits (HSA: $4,400 self / $8,750 family).
   Prevents employees from over-contributing and getting penalized.

3. DEDUCTIBLE TRACKING
   Shows deductible met vs. remaining — employees know exactly
   when insurance starts paying more. Drives smarter utilization.

4. EMPLOYER INTEGRATION
   Employer seed contributions, match rules, and open enrollment
   windows are all encoded — mirrors how UnitedHealth/Optum works.

5. SECURITY
   Every employee sees only their own data (JWT-scoped).
   Passwords are bcrypt hashed. No plain-text credentials.

6. SCALABLE
   NeonDB (serverless Postgres) scales automatically.
   Adding new employees = just insert a row. No code change.
